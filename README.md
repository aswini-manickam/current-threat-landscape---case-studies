# current-threat-landscape case-studies

A continuously updated collection of security incident case studies, each mapped to MITRE ATT&CK, with root-cause gap analysis and detection engineering work moving from written analysis toward hands-on, tested detection labs over time.

This repo is my working record of studies made on significant incident: which control category actually failed, why modern security threat failed to detect and what detection logic would have caught it or would catch a repeat.

Every case study follows the same structure - see case-studies/TEMPLATE.md:Summary, Key dates/events,MITRE ATT&CK Mapping,Gap Analysis, Detection Sketch, Hand-on Lab Status, Lessons & remediation
